## 1. Definitions

**Note (as a musical event)**
A symbolic event that describes what sound to play, when to start, how long it lasts, and how it should sound. It does **not** contain audio — it provides instructions to a synthesiser or sampler.

**Note Parameters**
| Parameter | Meaning | Example |
|---|---|---|
| Pitch | Which note to play | C4, D#4 |
| Onset | When the note starts | 0.0 beats |
| Duration | How long the note lasts | 1.0 beats |
| Dynamic | How loud to play | 0.0 – 1.0 |
| Instrument | Which sound source to use | sine, piano, violin |
| Articulation | How the note is played | staccato, legato |

**Note Durations (quarter note = 1 beat)**
| Note Name | Duration (beats) |
|---|---|
| Whole | 4.0 |
| Half | 2.0 |
| Quarter | 1.0 |
| Eighth | 0.5 |
| Sixteenth | 0.25 |

**Dotted Note**
A dot adds half of the original note duration. Each additional dot adds half of the previous addition.
- Quarter note = 1 beat
- Dotted quarter = 1.5 beats
- Double-dotted quarter = 1.75 beats

**Tie**
Joins adjacent notes of the same pitch into one sustained sound. Two tied quarter notes = one note of 2 beats.

**Tempo**
Describes the speed of musical time — how fast or slow the music feels.

**BPM (Beats Per Minute)**
How many reference beats occur in one minute. Higher BPM = faster tempo. Lower BPM = slower tempo.

**Onset**
When a note begins.

**Duration**
How long the note lasts.

**Offset**
When the note ends: `offset = onset + duration`.

**Beams**
Connect eighth notes and shorter note values. They usually do not change duration but show rhythmic grouping and beat structure.

**Rest**
Shows silence in musical notation. Half, quarter, and eighth rests have the same relative durations as their corresponding note values. A whole rest commonly represents a full measure of silence.

**Pitch**
Represented using a step (note letter), accidental, and octave number.

**Accidentals**
| Accidental | Symbol | Effect |
|---|---|---|
| Sharp | # | Raises a note by one semitone (half step) |
| Flat | b | Lowers a note by one semitone (half step) |
| Natural | ♮ | Cancels a previous sharp or flat |

**Enharmonic Equivalents**
Different note names that refer to the same pitch.
- C# = Db
- F# = Gb
- A# = Bb

**Octave**
Notes one octave apart have the same note name but sound higher or lower. They share the same pitch class (e.g. C3, C4, C5 are all "C").

**Chromatic Scale**
The complete set of 12 different pitch classes within one octave. In twelve-tone equal temperament (12-TET), an octave is divided into 12 equal semitones.

**The 12 Pitch Classes**
| Number | Sharp/Natural | Flat/Enharmonic |
|---|---|---|
| 0 | C | — |
| 1 | C# | Db |
| 2 | D | — |
| 3 | D# | Eb |
| 4 | E | — |
| 5 | F | — |
| 6 | F# | Gb |
| 7 | G | — |
| 8 | G# | Ab |
| 9 | A | — |
| 10 | A# | Bb |
| 11 | B | — |

**Equal-Tempered Tuning**
Each semitone step multiplies the frequency by the same ratio. After 12 semitones (one octave), the frequency doubles (multiplied by 2). Each semitone has a frequency ratio of **2^(1/12) ≈ 1.05946**, so each semitone is about a **5.95% increase** in frequency.

**Chord**
Two or more notes beginning together or overlapping in time. Simultaneous notes can be represented using the same onset.

**Polyphony**
Notes with different onsets and durations, with overlapping time intervals.

**Measure**
Groups musical events into recurring units.

**Time Signature**
Indicates the notated structure of measures (e.g. 4/4, 3/4, 6/8).

## 2. Explanations

### Note as Symbolic Event
- A note is **symbolic data**, not audio.
- It tells a synthesiser/sampler what to produce.
- Keeping events as structured data makes validation, processing, synthesis, and later changes easier to understand and maintain.

### Note Durations
- Notes have different durations determining how long they sound.
- Quarter note = 1 beat is the reference.
- Durations are often stored in a dictionary or lookup table mapping note names to lengths in beats.

### Dotted Notes and Ties
- A dot adds half the original duration.
- Each additional dot adds half of the previous addition.
- A tie joins adjacent notes of the same pitch into one sustained sound.

### Tempo and BPM
- Tempo = speed of musical time.
- BPM = beats per minute.
- **Key formula:** `seconds per beat = 60 / BPM`
- At 60 BPM: 1 beat every 1.0 s (60 ÷ 60 = 1.0)
- At 120 BPM: 1 beat every 0.5 s (60 ÷ 120 = 0.5)
- Increasing BPM shortens the duration of each beat (more beats in the same time → each beat is shorter).

### Onset, Duration, Offset
- Onset = when note begins.
- Duration = how long it lasts.
- Offset = onset + duration.

| Pitch | Onset | Duration | Offset |
|---|---|---|---|
| C4 | 0.0 | 1.0 | 1.0 |
| D4 | 1.0 | 1.0 | 2.0 |
| E4 | 2.0 | 2.0 | 4.0 |

### Beams and Rhythmic Grouping
- Beams connect eighth notes and shorter values.
- They don't change duration — they show rhythmic grouping and beat structure.
- Examples: two eighth notes beamed together; four sixteenth notes beamed together; mixed groups.

### Rests
- Rests show silence.
- Half, quarter, and eighth rests match the relative durations of their note counterparts.
- Whole rest = full measure (commonly).
- A rest can be represented in code by:
  1. Moving the current time forward (skip ahead by rest duration).
  2. Generating an array of zeros (digital silence).
  3. Using a missing note event (e.g. `None` in a melody list).

### Pitch in Software
- Notes are named A–G and modified with accidentals (#, b, ♮).
- Notes higher on a staff generally represent higher pitches, but exact pitch also depends on accidental and octave context.
- Pitch can be represented as `{step, accidental, octave}`, then combined into a name like `F#4`.

### Octaves
- Notes one octave apart share the same note name but sound higher or lower.
- They belong to different registers but share the same pitch class.
- Keyboard example: Octaves 3–5 — C3, C4, C5 are all "C".
- Semitone ruler (one octave): C=0, C#/Db=1, D=2, D#/Eb=3, E=4, F=5, F#/Gb=6, G=7, G#/Ab=8, A=9, A#/Bb=10, B=11, C=12.
- 12 semitones = 1 octave.

### Equal-Tempered Tuning & Frequency Formula
- Each semitone multiplies frequency by 2^(1/12) ≈ 1.05946.
- After 12 semitones, frequency doubles.

**Frequency Formula:**
```
frequency = reference_frequency × 2^(semitone_offset / 12)
```
- `reference_frequency` = frequency of reference note (usually A4 = 440 Hz).
- `semitone_offset` = number of semitones above (positive) or below (negative) the reference.

**Example (A4 = 440 Hz):**
- −12 semitones → 220 Hz → A3
- 0 semitones → 440 Hz → A4
- +12 semitones → 880 Hz → A5

**Examples of note conversion (A4 = 440 Hz):**
| Note | Semitones from A4 | Frequency |
|---|---|---|
| A3 | −12 | 220.00 Hz |
| C4 | −9 | 261.63 Hz |
| A4 | 0 | 440.00 Hz |
| A5 | +12 | 880.00 Hz |

### Chords and Polyphony
- **Sequential melody:** different onsets, notes occur one after another.
- **Chord:** same onset, different pitches — notes sound together.
- **Polyphony:** overlapping time intervals, different onsets and durations.
- In code, simultaneous notes share the same `onset`.

### Measures and Time Signatures
| Time Signature | Meaning |
|---|---|
| 4/4 | Four quarter-note units per measure |
| 3/4 | Three quarter-note units per measure |
| 6/8 | Six eighth-note subdivisions, commonly grouped into two larger beats |

### Articulation
| Articulation | Ratio | Effect on Notated Duration |
|---|---|---|
| staccato | 0.50 | Performed for 50% |
| normal | 0.90 | Performed for 90% |
| legato | 1.00 | Performed for 100% |

`performed_duration_seconds = notated_duration_seconds × articulation_ratio`

### Event Validation
`validate_event()` checks:
- Pitch name is valid (or REST)
- `onset_beats` is not negative
- `duration_beats` is greater than zero
- `dynamic` is between 0.0 and 1.0
- `articulation` is supported

### Processing Pipeline
```
MusicEvent → ProcessedEvent
```
ProcessedEvent contains:
- `frequency_hz`
- `onset_seconds`
- `notated_duration_seconds`
- `performed_duration_seconds`

### Synthesis & Envelope
- Without a short fade, a waveform can start or stop abruptly at a non-zero sample and create an audible click.
- Apply a short **attack/release envelope** to avoid clicks.

### Mixing & Polyphony in Code
- Place events on the output timeline.
- REST events occupy time but contribute no waveform.
- Notes with the same onset overlap → chord.
- **`+=` matters:** if two events occupy the same sample positions, their waveforms are added together — this is how chords and polyphony are created.

### Normalisation
- Polyphonic mixing can make the summed waveform exceed ±1.
- Normalisation scales it down while preserving the relative balance between notes.
- Only normalise if needed (peak > 1.0 and peak ≠ 0.0).

### Save and Inspect
- `save_wav()` converts floating-point waveform to 16-bit PCM WAV.
- `plot_audio()` displays the final waveform.
- `play_audio()` is optional; the file is still generated when playback is unavailable.

### Main Workflow
```
Create MelodySynthesizer
→ synthesize(MELODY)
→ print event information
→ save WAV
→ plot / optional playback
→ transpose example
```
Result: a small, testable pipeline: **symbolic events → processed events → waveform → output**.

### 3.3 Dotted Duration Function

```python
def dotted_duration(duration_beats, dots=1):
    total = duration_beats
    addition = duration_beats / 2
    for _ in range(dots):
        total += addition
        addition /= 2
    return total

print(dotted_duration(1.0))     # 1.5
print(dotted_duration(1.0, 2))  # 1.75
```

### 3.14 Note Name → Semitone Position

```python
def note_name_to_semitone_position(pitch_name: str) -> int | None:
    normalised = normalise_pitch_text(pitch_name)
    if normalised == "REST":
        return None
    match = PITCH_PATTERN.fullmatch(normalised)
    if match is None:
        raise ValueError("Invalid pitch name")
    letter, accidental, octave_text = match.groups()
    note_name = letter + accidental
    octave = int(octave_text)
    return octave * 12 + SEMITONES_FROM_C[note_name]
```
- Accepts names such as `C4`, `F#4`, `Bb3`, `F4`, `B3`.
- Octave contributes groups of 12 semitones; note name contributes its position inside the octave.
- `REST` returns `None` (silence has no frequency).

### 3.15 Note Name → Frequency

```python
def note_name_to_frequency(pitch_name: str,
                           reference_a4_hz: float = 440.0
                           ) -> float | None:
    position = note_name_to_semitone_position(pitch_name)
    if position is None:
        return None
    semitone_offset = position - A4_SEMITONE_POSITION
    return reference_a4_hz * 2 ** (semitone_offset / 12)
```

### 3.16 Beats to Seconds (Validated)

def beats_to_seconds(beats: float, bpm: float) -> float:

    if beats < 0:

### 3.18 Process Event

```python
def process_event(event: MusicEvent,
                  config: SynthesisConfig) -> ProcessedEvent:
    """Calculate frequency and real-time values
    for one symbolic event."""
    validate_event(event)
    frequency_hz = note_name_to_frequency(
        event.pitch,
        reference_a4_hz=config.reference_a4_hz,
    )
    onset_seconds = beats_to_seconds(event.onset_beats,
                                     config.bpm)
    notated_duration_seconds = beats_to_seconds(
        event.duration_beats, config.bpm
    )
    performed_duration_seconds = (
        notated_duration_seconds
        * articulation_ratio(event.articulation)
    )
    return ProcessedEvent(
        source_event=event,
        frequency_hz=frequency_hz,
        onset_seconds=onset_seconds,
        notated_duration_seconds=notated_duration_seconds,
        performed_duration_seconds=performed_duration_seconds,
    )
```

### 3.19 Generate Sine Wave

```python
def generate_sine_wave(
    frequency_hz: float,
    duration_seconds: float,
    dynamic: float,
    sample_rate: int,
) -> np.ndarray:
    number_of_samples = max(
        1, int(round(duration_seconds * sample_rate))
    )
    time = np.arange(number_of_samples) / sample_rate
    return dynamic * np.sin(
        2.0 * np.pi * frequency_hz * time
    )
```
- `frequency_hz` controls how quickly the sine wave oscillates.
- `duration_seconds` and `sample_rate` determine the number of generated samples.
- `dynamic` multiplies the waveform and controls amplitude.

### 3.21 Place Events on Output Timeline

```python
for event in processed_events:
    if event.frequency_hz is None:
        continue  # REST

    note_audio = self.synthesize_note(event)
    start_sample = int(round(
        event.onset_seconds * self.config.sample_rate
    ))
    end_sample = min(
        start_sample + len(note_audio), len(output)
    )
    output[start_sample:end_sample] += (
        note_audio[:end_sample - start_sample]
    )
```
- REST events occupy time but contribute no waveform.
- At beat 4, C4, E4, and G4 share the same onset and overlap for two beats → chord.
- **`+=` matters:** if two events occupy the same sample positions, their waveforms are added together — this is how chords and polyphony are created.

### 3.22 Normalise Audio

```python
def normalize_audio(audio, target_peak=0.95):
    peak = float(np.max(np.abs(audio)))
    if peak <= 1.0 or peak == 0.0:
        return audio.copy()
    return audio * (target_peak / peak)
```
- Polyphonic mixing can make the summed waveform exceed ±1.
- Normalisation scales it down while preserving the relative balance between notes.
