## 1. Definitions

**Sound Synthesis**
The generation of audio signals using electronic or computational methods.

**Synthesis Techniques**
Techniques differ in how they generate and control the spectral and temporal evolution of a sound.
- Subtractive synthesis
- Additive synthesis
- FM and phase-modulation synthesis
- Sample-based synthesis
- Wavetable synthesis
- Vector synthesis and wave sequencing
- Granular synthesis
- Physical-modelling synthesis

**Oscillator**
Generates a periodic signal.

**Basic Oscillator Parameters**
| Parameter | Determines |
|---|---|
| Frequency | How rapidly the waveform repeats |
| Amplitude | The waveform's magnitude |
| Waveform shape | Harmonic structure |

**Harmonics**
For a fundamental frequency \(f\), harmonics occur at \(f, 2f, 3f, 4f, \ldots\)

**Waveform Shapes (Oscillator Types)**
| Waveform | Harmonic Content | Character |
|---|---|---|
| Sine | One frequency component only | Pure tone with only the fundamental |
| Triangle | Odd harmonics, amplitudes decrease approx. \(1/n^2\) | Soft tone with mainly odd harmonics that fade quickly |
| Square | Odd harmonics, amplitudes proportional to \(1/n\) | Bright hollow tone with odd harmonics only |
| Pulse | Harmonic pattern depends on duty cycle | Variable-duty waveform with a thinner, nasal sound |
| Sawtooth | Both odd and even harmonics, amplitudes decrease approx. \(1/n\) | Bright buzzy tone containing all harmonics |
| Noise | Aperiodic broadband source | Random signal with energy spread across many frequencies |

**Note:** A square wave is a special pulse wave with a 50% duty cycle.

**Simple Waveform**
- Has a regular, repeating shape
- Usually generated by a single oscillator
- Contains one frequency component or a predictable set of harmonics
- Often has a relatively static timbre
- Example: A sine wave contains one ideal frequency component.

**Complex Waveform**
- Contains multiple frequency components or partials
- May change in shape, spectrum, and amplitude over time
- Can be produced by combining, filtering, modulating, sampling, or modelling sounds
- Produces richer and more varied timbres
- Examples: Musical instruments, speech, and most synthesised sounds.

**Aliasing**
A digital oscillator cannot correctly represent frequency components at or above half the sample rate. Harmonics above the Nyquist frequency fold into lower frequencies as aliases.

**Nyquist Frequency**
\[
f_{\mathrm{Nyquist}} = \frac{f_{\mathrm{s}}}{2}
\]
At 44,100 Hz: \(f_{\mathrm{Nyquist}} = 22,050\) Hz.

**Filter**
Changes the spectral content of a sound. In subtractive synthesis, a harmonically rich oscillator provides the source, and a filter removes or emphasises selected frequency regions.

**Main Filter Parameters**
| Parameter | Meaning |
|---|---|
| Cutoff frequency | Boundary around which attenuation begins |
| Resonance / Q | Emphasis around the cutoff |
| Order / slope | How rapidly the filter attenuates frequencies beyond cutoff |
| Key tracking | Changes cutoff according to played pitch |
| Modulation amount | How strongly an envelope, LFO, or control signal changes cutoff |

**Filter Response Types**
| Type | Effect |
|---|---|
| Low-pass | Retains frequencies below the cutoff |
| High-pass | Retains frequencies above the cutoff |
| Band-pass | Retains frequencies within a selected range |
| Band-stop / notch | Attenuates frequencies within a selected range |

**ADSR Envelope**
Describes control evolution, not a waveform. The envelope is multiplied by or mapped onto another parameter. The amplitude envelope controls loudness evolution; a filter envelope can use a similar ADSR shape while controlling cutoff frequency.

| Stage | Meaning |
|---|---|
| Attack | Time from note-on to maximum |
| Decay | Time from maximum to sustain |
| Sustain | Level maintained while the note is active |
| Release | Time from note-off to silence |

**Key point:** Attack, decay, and release are **times**. Sustain is a **level**.

**LFO (Low-Frequency Oscillator)**
An oscillator whose output is normally used as a control signal rather than heard directly.

| LFO destination | Effect |
|---|---|
| Pitch | Vibrato |
| Amplitude | Tremolo |
| Filter cutoff | Cyclic timbral movement |
| Pan | Stereo movement |

**Subtractive Synthesis**
Start with a harmonically rich waveform, then subtract frequencies using a filter. Strongly associated with analogue synthesisers of the 1960s and 1970s; digital synthesis became prominent in the 1980s; later virtual-analogue instruments modelled or reproduced subtractive architectures in software. Still widely used across many genres.

**Additive Synthesis**
Constructs complex sounds by summing simpler sinusoidal components. Closely related to Fourier analysis, but practical additive synthesis may use harmonic or inharmonic partials with time-varying amplitudes and frequencies.

**FM Synthesis (Frequency Modulation)**
A modulator oscillator changes the frequency of a carrier oscillator, producing a richer sound with sidebands. Developed by John Chowning at Stanford in the late 1960s and early 1970s. Yamaha later licensed the technique and used related digital implementations in commercial synthesisers such as the DX7. The synthesis engine was much more difficult to understand than subtractive and additive synthesis. FM synthesis remains widely available in hardware, software, plugins, and game-audio systems.

**Carrier**
The oscillator whose frequency is being modulated. Base frequency = \(f_c\).

**Modulator**
The oscillator that produces the modulation signal. Frequency = \(f_m\).

**Modulation Index (I)**
Controls how strongly the modulator affects the carrier.

**Sidebands**
FM synthesis generates additional frequency components at:
\[
f_c \pm n f_m
\]
where \(n = 1, 2, 3, \ldots\)

## 2. Explanations

### From Symbolic Music to Audio
```
Notation / ABC / MusicXML / MIDI
→ Structured musical event
→ Parameter mapping (pitch → frequency, beats → seconds, dynamic → synthesis control)
→ Synthesis algorithm
→ Audio samples
```

### General Pipeline for Audio Synthesis
1. **Define note events** — pitch, onset, duration, dynamic, articulation.
2. **Convert pitch names to frequencies** — e.g. A4 = 440 Hz.
3. **Convert beats to seconds** — use tempo (BPM).
4. **Generate one note using the selected synthesis method** — additive, subtractive, FM, wavetable, etc.
5. **Apply envelope, dynamics, and articulation** (optional) — shape loudness and note character with ADSR, velocity, and articulation rules.
6. **Place and/or mix overlapping notes on the timeline while protecting against clipping** — position notes, mix overlapping sounds, normalize or limit.
7. **Play and save** — send audio to playback and/or write to a WAV file.

### Simple vs Complex Waveforms
- **Simple waveform:** regular, repeating shape; single oscillator; one frequency component or predictable harmonics; often static timbre.
- **Complex waveform:** multiple frequency components or partials; may change over time; produced by combining, filtering, modulating, sampling, or modelling; richer and more varied timbres.

**Demonstration:** Complex waveforms such as sawtooth and square can be built by summing sine waves. The more harmonics included, the closer the generated waveform becomes to its ideal shape.

### Aliasing and Nyquist
- A digital oscillator cannot correctly represent frequency components at or above half the sample rate.
- Harmonics above the Nyquist frequency fold into lower frequencies as aliases.
- Aliasing creates inharmonic components that move in the wrong direction as oscillator pitch changes.
- **Rule:** the highest generated frequency should be less than or equal to half of the sampling rate.

**Example:** At 44.1 kHz sample rate, Nyquist = 22,050 Hz. For a fundamental of 8 kHz, the third harmonic is 24 kHz — this exceeds Nyquist and cannot be represented correctly.

### Filters
A filter changes the spectral content of a sound. In subtractive synthesis, a harmonically rich oscillator provides the source, and a filter removes or emphasises selected frequency regions.

**Low-pass filter behaviour:**
- Allows frequencies below the cutoff; reduces higher frequencies.
- **Cutoff controls brightness:** a lower cutoff produces a darker sound.
- **Resonance** boosts harmonics near the cutoff, making the tone more focused or sharper.
- The final tone depends mainly on the cutoff and resonance settings.

### ADSR Envelope
- Attack: time from note-on to maximum.
- Decay: time from maximum to sustain.
- Sustain: level maintained while the note is active.
- Release: time from note-off to silence.
- **Attack, decay, and release are times. Sustain is a level.**
- ADSR describes control evolution, not a waveform. The envelope is multiplied by or mapped onto another parameter.

### LFO and Modulation
An LFO is an oscillator whose output is normally used as a control signal rather than heard directly. Generating an LFO is similar to generating a normal wave, but at a low frequency.

### Subtractive Synthesis
**Signal flow:**
```
Keyboard / MIDI note (pitch + gate)
→ Oscillator(s): harmonically rich source (saw, square/pulse, triangle, noise)
→ Mixer: combine multiple oscillators
→ Filter (VCF): removes frequencies (cutoff, resonance)
→ Amplifier (VCA): controls overall level
→ Output
```

**Control paths:**
- LFO → modulate pitch (vibrato), filter cutoff (wah), amplitude (tremolo)
- Filter Envelope (ADSR) → modulate filter cutoff
- Amp Envelope (ADSR) → modulate amplifier level (volume)

**How subtractive synthesis works:**
- Start with a harmonically rich waveform (e.g. saw, square, noise).
- Use a filter to remove (subtract) unwanted frequencies.
- Shape the sound over time with envelopes and LFOs.

**Basic principles:**
1. Mix the outputs of multiple sound-generating oscillators (triangle, square, pulse, sawtooth, noise).
2. Pass the combined waveform through a filter (most often low-pass) that removes or enhances certain frequencies using a resonance control.
3. The filter is altered dynamically using an ADSR envelope (attack, decay, sustain, release).
4. The attack is triggered on note-on; decay and sustain follow automatically; release is triggered on note-off.
5. The amplitude envelope and filter envelope are usually separate, even if both use ADSR stages.

**Step-by-step:**
1. Generate a waveform — usually a harmonically rich source like sawtooth or square.
2. Use a filter to enhance or attenuate certain frequencies — commonly low-pass, but band-pass or high-pass are also used.
3. Use an envelope to change the waveform's amplitude over time — the classic ADSR envelope controlling loudness.
4. Use an envelope to dynamically adjust the filtering over time — a filter envelope (often separate from the amplitude envelope) modulates cutoff frequency for timbral changes.
5. Use low-frequency oscillators to add more dynamic interest — LFO modulates pitch, amplitude, filter cutoff, pulse width, pan, wavetable position, or other parameters.

**Sample sounds offered by subtractive synthesis:**
- Deep basses
- Searing leads
- Sweeping pads
- Resonant filters
- Filter sweeps

**Well-known subtractive synthesiser:** the Minimoog.

### Additive Synthesis
**Idea:** Explain one complicated wave as a combination of many smaller, simpler waves.

**Signal flow:**
```
Oscillator / Partial 1 (fundamental, f1 = f0)
Oscillator / Partial 2 (2nd harmonic, f2 = 2f0)
Oscillator / Partial 3 (3rd harmonic, f3 = 3f0)
...
→ Level / Amplitude control for each partial (A1, A2, A3, ...)
→ SUM / MIXER
→ Envelope (optional): overall amplitude over time (e.g. ADSR)
→ Output: complex waveform and spectrum
```

**Principles:**
- Generate a simple sine wave at the pitch of the note.
- Generate a whole set of sine waves at (usually) harmonic frequencies.
- The frequencies of harmonic partials are integer multiples of the fundamental pitch.
- Adding more audible partials can make the sound spectrally richer, but timbre also depends on their amplitudes, phases, and time evolution.
- Use an envelope to change the waveform's amplitude over time — each partial may use a separate envelope.
- Use low-frequency oscillators to add more dynamic interest.

**Additive synthesis** creates a complex sound by adding several sine-wave frequency components together. Each component has a frequency, amplitude, phase, and potentially a time-varying envelope. The synthesiser is represented as a set of \(N\) sine-wave oscillators; each oscillator receives a value for amplitude and frequency, and they are then simply added to produce the complex wave output.

**Key limitation:** Additive synthesis can require many parameters and considerable computation when large numbers of independently controlled partials are used.

### Adding Harmonics and Partials
- **Harmonics** have integer-multiple frequencies.
- **Inharmonic partials** do not.
- Real sounds may contain both.
- Partial amplitudes often change independently over time.
- Harmonics may have different amplitudes; their relative amplitudes influence the resulting timbre.
- In many sounds, higher harmonics are weaker than lower harmonics, but the spectral pattern depends on the sound source and changes over time.

**Example (A4 = 440 Hz):**
| Harmonic | Frequency |
|---|---|
| 1st | 440 × 1 = 440 Hz |
| 2nd | 440 × 2 = 880 Hz |
| 3rd | 440 × 3 = 1320 Hz |
| 4th | 440 × 4 = 1760 Hz |
| 5th | 440 × 5 = 2200 Hz |

Combined waveform = sum of the selected harmonics.

### FM Synthesis
**How it works:**
1. The modulator generates a low- or audio-rate sine wave.
2. That signal continuously shifts the carrier frequency up and down.
3. The result is a richer tone with new spectral components (sidebands).

**Basic principles:**
1. **Generate a modulator waveform** — the modulator oscillator produces a signal that will vary the frequency of the carrier.
2. **Control the strength of modulation** — the modulator's amplitude determines the modulation index (modulation depth), which affects brightness and timbre.
3. **Use the modulator to vary the carrier frequency** — the carrier oscillator has its frequency changed continuously by the modulator signal.
4. **Shape the output amplitude over time** — the carrier usually has its own amplitude envelope to control loudness over time.
5. **Result: a richer spectrum** — FM produces new spectral components called sidebands, which create more complex timbres.

**Effect of parameters:**
- **Carrier-to-Modulator Ratio (\(f_c / f_m\)):**
  - Integer ratios (e.g. 1:1, 2:1, 3:2) → predominantly harmonic spectra.
  - Non-integer ratios (e.g. 1.4:1, 2.7:1) → inharmonic spectra, often perceived as bell-like, metallic, or percussion-like.
- **Modulation Index (I):**
  - Small values → simpler, sine-like timbres.
  - Larger values → more sidebands and richer spectra.
  - Increasing I generally increases spectral complexity.
- **Sidebands:**
  - FM generates additional frequency components at \(f_c \pm n f_m\), where \(n = 1, 2, 3, \ldots\)
  - The carrier-to-modulator ratio determines the location of sidebands in the spectrum.
  - The modulation index determines how many sidebands have significant amplitude.

**Summary:** FM synthesis creates complex timbres by using one oscillator (the modulator) to vary the frequency of another oscillator (the carrier). The carrier-to-modulator ratio determines whether the spectrum is harmonic or inharmonic, while the modulation index controls spectral complexity and the number of audible sidebands.

### 3.2 Pitch Name to Frequency

```python
def pitch_to_frequency(pitch):
    if pitch.lower() == "rest":
        return None

    note_numbers = {
        "C": 0, "C#": 1, "D": 2, "D#": 3,
        "E": 4, "F": 5, "F#": 6, "G": 7,
        "G#": 8, "A": 9, "A#": 10, "B": 11,
    }

    note = pitch[:-1]
    octave = int(pitch[-1])

    midi_number = 12 * (octave + 1) + note_numbers[note]

    return 440 * (2 ** ((midi_number - 69) / 12))
```

This simplified function supports natural notes and sharps with one-digit octave numbers. The calculation uses MIDI-style semitone numbering internally, but the synthesis output is a frequency in hertz.

### 3.3 Beats to Seconds

```python
def beats_to_seconds(beats, tempo=120):
    return beats * 60.0 / tempo
```

The `beats_to_seconds()` function converts musical time (beats) into real time (seconds). This allows note events to be defined independently of tempo and then translated into the correct durations for audio synthesis.

**Example:** At 120 BPM, one beat equals 0.5 seconds, so a note lasting 2 beats will be rendered for 1 second.

### 3.4 ADSR Envelope

```python
def create_adsr_envelope(gate_duration, attack_time,
                          decay_time, sustain_level,
                          release_time):
    # Note-on phase
    attack_samples = int(attack_time * SAMPLE_RATE)
    decay_samples = int(decay_time * SAMPLE_RATE)
    sustain_duration = max(
        0, gate_duration - attack_time - decay_time
    )
    sustain_samples = int(sustain_duration * SAMPLE_RATE)

    attack = np.linspace(0, 1, attack_samples, endpoint=False)
    decay = np.linspace(1, sustain_level, decay_samples, endpoint=False)
    sustain = np.full(sustain_samples, sustain_level)
    note_on_part = np.concatenate([attack, decay, sustain])

    # Note-off phase
    release_samples = int(release_time * SAMPLE_RATE)
    release = np.linspace(sustain_level, 0, release_samples)
    envelope = np.concatenate([note_on_part, release])

    return envelope
```

### 3.5 LFO

```python
def lfo(rate_hz, duration, sample_rate, depth=1.0):
    time = np.arange(int(duration * sample_rate)) / sample_rate
    return depth * np.sin(2 * np.pi * rate_hz * time)
```

Generating an LFO is similar to generating a normal wave, but at a low frequency.

### 3.6 Subtractive Synthesis

```python
def synthesis_function(frequency, duration, amplitude):
    t = np.linspace(0, duration,
                    int(duration * SAMPLE_RATE), False)
    waveform = sawtooth(2 * np.pi * frequency * t)
    cutoff_frequency = 4000
    sos = butter(4, cutoff_frequency,
                 btype="lowpass",
                 fs=SAMPLE_RATE, output="sos")
    waveform = sosfilt(sos, waveform)

    waveform /= np.max(np.abs(waveform))

    return amplitude * waveform
```

### 3.7 Additive Synthesis

```python
def synthesis_function(frequency, duration, amplitude):
    t = np.linspace(0, duration,
                    int(duration * SAMPLE_RATE), False)
    waveform = (
        np.sin(2 * np.pi * frequency * t)
        + 0.5 * np.sin(2 * np.pi * 2 * frequency * t)
        + 0.3 * np.sin(2 * np.pi * 3 * frequency * t)
        + 0.2 * np.sin(2 * np.pi * 4 * frequency * t)
    )
    waveform /= np.max(np.abs(waveform))
    return amplitude * waveform
```

A simple implementation of additive synthesis in Python is provided in the file `additive_synthesis.py` on Moodle.

**Additive Synthesis Equation:**
\[
output(t) = \sum_{n=1}^{N} A_n \sin(2\pi f_n t + \phi_n)
\]
- \(A_n\) = amplitude of the \(n\)-th frequency component
- \(f_n\) = frequency of that frequency component
- \(\phi_n\) = phase of the frequency component
- \(N\) = number of frequency components being added
- \(output(t)\) = resulting waveform over time

For harmonic additive synthesis, the frequencies are often multiples of the fundamental frequency, e.g. \(f_n = n f_0\). Changing the amplitudes of the harmonics changes the timbre of the resulting sound.

### 3.8 FM Synthesis

```python
def synthesis_function(frequency, duration, amplitude):
    t = np.linspace(0, duration,
                    int(duration * SAMPLE_RATE), False)

    # Equation parameters
    A = amplitude
    fc = frequency        # Carrier frequency
    fm = frequency * 2    # Modulator frequency
    I = 5                 # Modulation index

    # y(t) = A sin(2π f_c t + I sin(2π f_m t))
    waveform = A * np.sin(
        2 * np.pi * fc * t
        + I * np.sin(2 * np.pi * fm * t)
    )

    return waveform
```

A simple implementation of FM synthesis in Python is provided in the file `fm_synthesis.py` on Moodle.

**FM Synthesis Equation:**
\[
y(t) = A \sin(2\pi f_c t + I \sin(2\pi f_m t))
\]
- \(A\) = output amplitude
- \(f_c\) = carrier frequency
- \(f_m\) = modulator frequency
- \(I\) = modulation index

### 3.9 Create Melody (Mix and Protect Against Clipping)

```python
def create_melody(events):
    total_beats = max(
        e["onset_beats"] + e["duration_beats"]
        for e in events
    )
    total_seconds = beats_to_seconds(total_beats)
    melody = np.zeros(int(total_seconds * SAMPLE_RATE))

    for event in events:
        note_audio = synthesize_event(event)
        if note_audio is None:
            continue
        start_sample = int(
            beats_to_seconds(event["onset_beats"])
            * SAMPLE_RATE
        )
        end_sample = start_sample + len(note_audio)
        melody[start_sample:end_sample] += note_audio

    melody /= np.max(np.abs(melody))

    return melody
```
