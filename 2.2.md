## 1. Definitions

**ABC Notation**
A plain-text notation system for representing musical scores using letters, numbers, and symbols. Designed to be simple, readable, and easy to process by both people and computers.

**Why ABC is useful in music programming:**
1. Human-readable and editable without specialist software.
2. Compact representation of notes, rests, and rhythm.
3. Easy to store, share, search, and version-control.
4. Suitable for parsing and algorithmic transformation.
5. Can be rendered as conventional notation.
6. Can be converted into performance events.

**Header**
Contains metadata and interpretation settings. Ends at `K:`.

**Tune Body**
Contains musical tokens: pitches and octaves, note lengths, rests, accidentals, bar lines and repeats, chords, and other notation instructions.

**Header Fields**
| Field | Meaning | Example |
|---|---|---|
| X: | Reference number (usually unique) | X:1 |
| T: | Title | T:Simple Melody |
| C: | Composer/source attribution | C:Traditional |
| M: | Meter / time signature | M:4/4 |
| L: | Unit note length (default) | L:1/4 |
| Q: | Tempo | Q:1/4=100 |
| K: | Key | K:C |

**Required header fields:** `X`, `T`, `K`. Without these, the ABC is invalid. `L` is optional but a warning is printed if missing.

**ABC Note Symbol — Syntax Order**
```
accidental + note letter + octave marks + length modifier
```
1. **Accidental** (optional): `^` = sharp, `_` = flat, `=` = natural, `^^` = double sharp, `__` = double flat.
2. **Note letter**: `A–G` (uppercase), `a–g` (lowercase, one octave higher), `z` = rest.
3. **Octave marks**: commas `,` lower by one octave each; apostrophes `'` raise by one octave each.
4. **Length modifier**: `2`, `4`, `/2`, etc. Comes last, even after octave marks.

Example: `c'4` = high C lasting four unit lengths.

**ABC Rests**
`z` = visible rest. Uses the same length modifiers as notes.

**ABC Accidentals**
| Symbol | Meaning |
|---|---|
| `^` | Sharp |
| `_` | Flat |
| `=` | Natural |
| `^^` | Double sharp |
| `__` | Double flat |

**ABC Bar Lines**
| Symbol | Meaning |
|---|---|
| `|` | Bar line |
| `|]` | End of piece |
| `:|` | End of repeat |

**ABC Chords**
Simultaneous notes are written inside square brackets: `[CEG]2` = C-major chord lasting twice the unit note length.

**ABC Comments**
Use `%` for comments.

**ABC Beams**
Two or more eighth or sixteenth notes are beamed by writing them next to each other with no spaces.

## 2. Explanations

### ABC Overview
ABC is a **compact serialisation of musical information**. It sits between a music sheet and Python events:

```
Music sheet → ABC → Python events
```

### Header vs Body
- **Header** tells us how to interpret the music.
- **Body** contains the notes and symbols to play/read.
- After `K:`, the music body begins.
- Ignore blank lines and lines starting with `%` (comments).

### Pitch and Octaves in ABC
- Note letters `A–G` represent pitches.
- **Lowercase** letters (`a–g`) are higher in pitch than uppercase (`A–G`).
- **Commas** (`,`) after a note letter lower the note by one octave each.
- **Apostrophes** (`'`) after a note letter raise the note by one octave each.

Examples:
| ABC symbol | Result |
|---|---|
| C | C4 |
| c | C5 |
| C, | C3 |
| ^F | F#4 |
| _B | Bb4 |
| z | REST |

**Rule of thumb:** Uppercase letters start around octave 4; lowercase letters start around octave 5.

### Note Duration is Relative to L:
In ABC, note durations are calculated relative to the value set in the `L:` field (default note length), **not** directly from the meter (`M:` field).

Example: `L:1/16`
| ABC note | Name | Duration (whole notes) |
|---|---|---|
| A | Sixteenth note | 1/16 |
| A2 | Eighth note | 2/16 = 1/8 |
| A4 | Quarter note | 4/16 = 1/4 |
| A8 | Half note | 8/16 = 1/2 |

**Actual duration formula:**
```
actual duration = unit note length × length modifier
```

### Length Modifiers
| Modifier | Meaning | Multiplier of L |
|---|---|---|
| (none) | Default length | 1 |
| `/` | Half | 1/2 |
| `2` | Double | 2 |
| `3` | Three times | 3 |
| `3/2` | One and a half | 3/2 |
| `/4` | One quarter | 1/4 |

### Tempo (Q:)
`Q:1/4=100` means 100 quarter-note beats per minute.

```
seconds_per_beat = 60.0 / bpm
```
At 100 BPM, 1 beat = 0.6 seconds.

### Durations in This Tune (example)
- `L:1/8` means one default note = 0.5 beats.
- `C8` = 4 beats.

### Accidentals Resolution Order (`_resolve_pitch`)
1. Checks explicit accidentals first (`^F` → F#4, `_B` → Bb4).
2. Otherwise uses measure accidentals if present (a sharp earlier in the measure affects later notes).
3. Otherwise falls back to the key signature (key signature provides default accidentals).

### Chords in ABC
- `[CEG]2` = C, E, G sound together; `2` means twice the unit note length.
- All notes in the chord share the **same onset**, so they start together.
- In code, each pitch is synthesized separately, then mixed.

### Polyphonic Mixing
- `+=` adds overlapping notes into the same samples.
- Chord tones share the same onset but each pitch is synthesized separately.
- Example: C4 (261.6 Hz) + E4 (329.6 Hz) + G4 (392.0 Hz) → mixed waveform (chord).

### Envelope
- Without a short fade, a waveform can start or stop abruptly at a non-zero sample and create an audible click.
- Apply an **attack/release envelope** to shape the start and end of the tone.
- Typical values: `attack_seconds = 0.01`, `release_seconds = 0.03`.
- Envelope stages: **Attack → Hold → Release**.

### High-Level Pipeline
```
ABC source text
→ Split header and body
→ Parse musical meaning (durations, tempo, pitches, rests, chords)
→ Build symbolic events (MusicalEvent)
→ Convert to frequencies and timing
→ Sine-wave synthesis + polyphonic mix
→ WAV output + waveform + playback
```

### Important Classes / Functions
- `ApplicationConfig`
- `AbcParser`
- `SineWaveSynthesizer`
- `AbcMusicApplication`

### Output Stage
- `save_wav(audio, path)` → writes a 16-bit PCM WAV file.
- `plot_waveform(audio)` → visualizes the signal.
- `play_audio(audio)` → optional playback with sounddevice.

### Main Function Wiring
```
parse → render → save → show → play
```

## 3. Code

### 3.1 Splitting Header and Body

```python
def split_abc(abc_text):
    header = {}
    body_lines = []
    for line in abc_text.strip().splitlines():
        line = line.strip()
        if not line or line.startswith("%"):
            continue
        if len(line) >= 2 and line[1] == ":":
            field = line[0]
            value = line[2:].strip()
            header[field] = value
        else:
            body_lines.append(line)
    body = "".join(body_lines)
    return header, body
```

**Example input:**
```
X:1
T:The Kesh Jig
C:Traditional
M:6/8
K:D
% a comment line
DAB cde | fga bag | edb DBA |
```

**Output:**
```
header:
{'X': '1', 'T': 'The Kesh Jig', 'C': 'Traditional', 'M': '6/8', 'K': 'D'}

body:
'DAB cde | fga bag | edb DBA |'
```

### 3.2 Validating the Header

```python
def validate_header(header):
    required = {"X", "T", "K"}
    missing = required - header.keys()
    if missing:
        raise ValueError(
            f"Missing required ABC fields: {sorted(missing)}"
        )
    if "L" not in header:
        print("Warning: no explicit unit note length.")
```

### 3.3 Parsing Length Modifiers

```python
from fractions import Fraction

def parse_length_modifier(text):
    if text == "":
        return Fraction(1, 1)
    if text == "/":
        return Fraction(1, 2)
    if text.startswith("/"):
        denominator = int(text[1:])
        return Fraction(1, denominator)
    if "/" in text:
        numerator, denominator = text.split("/")
        return Fraction(int(numerator), int(denominator))
    return Fraction(int(text), 1)
```

**Examples:**
| Input | Output (Fraction) |
|---|---|
| `""` | `Fraction(1, 1)` |
| `"2"` | `Fraction(2, 1)` |
| `"/"` | `Fraction(1, 2)` |
| `"/4"` | `Fraction(1, 4)` |
| `"3/2"` | `Fraction(3, 2)` |

### 3.4 ABC Duration to Beats

```python
def abc_duration_to_beats(unit_length,
                          modifier_text=""):
    modifier = parse_length_modifier(modifier_text)
    whole_note_fraction = unit_length * modifier
    return float(whole_note_fraction * 4)
```

### 3.6 Note Name → Frequency

```python
def note_name_to_frequency(
    pitch_name: str,
    reference_a4_hz: float = 440.0
) -> float:
    # semitone_offset: how many semitones from A4
    # (positive = higher, negative = lower)
    semitone_offset = (
        semitone_position - a4_position
    )
    # convert semitone offset to frequency
    return reference_a4_hz * 2 ** (semitone_offset / 12)
```

**How it works:**
1. Read the letter, accidental, and octave (e.g. `"C#4"` → C#, 4).
2. Convert to a semitone position (map note to a number, count of semitones).
3. Compare with A4 (find the semitone offset from A4 = 440 Hz).
4. Use equal temperament formula:
   ```
   frequency = 440.0 × 2^(semitone_offset / 12)
   ```

**Examples:**
| Note | Frequency |
|---|---|
| A4 | 440 Hz |
| A5 | 880 Hz |
| A3 | 220 Hz |

Same formula works for C4, E4, G4, etc.

### 3.8 Sine-Wave Synthesis and Envelope

```python
def _synthesize_tone(
    self,
    frequency_hz: float,
    duration_seconds: float,
    amplitude: float,
) -> np.ndarray:

    # 1. choose how many samples are needed
    number_of_samples = max(
        1,
        int(round(
            duration_seconds * self._config.sample_rate
        )),
    )

    # 2. build a time axis
    time = np.arange(number_of_samples) / self._config.sample_rate

    # 3. generate a sine wave
    tone = amplitude * np.sin(
        2.0 * np.pi * frequency_hz * time
    )

    # 4. apply envelope and return
    return tone * self._make_envelope(number_of_samples)
```

**What each line means:**
1. Choose how many samples are needed — convert duration (seconds) to number of samples using sample rate. Ensure at least 1 sample.
2. Build a time axis — array of time values from 0 to duration, one value per sample.
3. Generate a sine wave — compute a sine wave at the desired frequency for each time sample.
4. Scale it by amplitude — multiply the sine wave by the requested amplitude (volume).
5. Apply an attack/release envelope — shape the start and end to avoid harsh clicks.

**Envelope values:**
```python
attack_seconds = 0.01
release_seconds = 0.03
```
