## 1. Definitions

**Sample-based Synthesis**
Generates notes from recorded audio. A sampler selects a source sample, changes its playback parameters, applies envelopes or filters, and mixes the result into the output.

- First samplers appeared in the 1970s but only became affordable for most musicians in the late 1980s.
- Very popular in modern music.
- Requires a lot of digital memory to store samples in the synthesiser.
- Difficult to get very natural expression with sample-based synthesisers.

**Sample**
A stored waveform (recorded audio) rather than a mathematically generated oscillator. Examples: piano, drum, voice, or synth sound.

**Sampling**
Uses a set of recordings of a real instrument and plays them back. It can sound perfect but is limited by the number of recordings you need to make and store.

**Stretch Factor (Playback Rate Ratio)**
\[
r = 2^{\frac{n}{12}}
\]
- \(r\) = playback-rate ratio
- \(n\) = transposition in semitones

| Transposition | Playback Rate |
|---|---|
| −12 semitones | 0.5 |
| −5 semitones | ≈ 0.749 |
| 0 semitones | 1.0 |
| +7 semitones | ≈ 1.498 |
| +12 semitones | 2.0 |

**Vector Synthesis**
Dynamic mixing of multiple simultaneous sound sources, commonly four sources arranged around an XY plane. The control position determines each source's contribution. Moving the position changes the mixture and therefore the timbre. Sources may be oscillators, samples, or a synthesis technique. The path may be controlled by a joystick, envelope, LFO, MIDI controller, or automation.

**Timbral Interpolation (Morphing)**
Calculating intermediate states between two sound representations. Linear interpolation:
\[
y(t) = (1-\alpha)A(t) + \alpha B(t)
\]
\[
\alpha = 0 \to A,\quad \alpha = 0.5 \to \text{equal mixture},\quad \alpha = 1 \to B
\]

**Wave Sequencing**
Scheduling different waves or samples over time. Each step may specify: source wave or sample, duration, pitch offset, amplitude, crossfade time, repeat or probability.

## 2. Explanations

### Sample-based Synthesis — Workflow
1. **Record or load a sample** — start with recorded audio (piano, drum, voice, synth sound). A sample is a stored waveform rather than a mathematically generated oscillator.
2. **Map samples to notes / keys** — assign one or more samples to MIDI note ranges. Different samples may be used for different pitches or playing styles (e.g. C1–D#2 = low sample, E2–G3 = mid sample, G#3–C5 = high sample).
3. **Trigger with MIDI or note events** — note number selects the target pitch. Velocity can choose a louder/brighter sample layer.
4. **Pitch and timing playback** — the sample is transposed to the requested note. Playback rate changes pitch (and often duration unless time-stretching is used).
5. **Shape the sound** — apply amplitude envelope (ADSR), optional filter, and looping for sustain. Loop points help extend held notes smoothly.
6. **Mix and output audio** — multiple triggered samples are mixed on the timeline. Result: the final audio output.

**Key idea:** Sample-based synthesis plays back recorded sounds and controls them with note events, pitch mapping, envelopes, and mixing.

### Sampling
- Digitally record a number of notes across the range of an instrument.
- Associate each sample with a group of keys on the keyboard.
- Within each group, the sample's pitch is shifted depending on the key played.
- Effects can be used to enhance the sound.

### Vector Synthesis
**Idea began in the 1980s but was refined in the 1990s.**

Use a number of different samples and connect them together. This creates an evolving timbre and adds lots of interest to the sound.

**Sequential's Vector Synthesis:**
- The VS had a joystick that allowed the user to take any path between the starting and end positions of the oscillator mix.
- 96 waveforms were supplied as standard (including sine, sawtooth, square, and various widths of pulse).
- The VS also allowed users to create their own waveforms through a basic form of additive synthesis: stepping through the various harmonics and specifying a level for each, with the resulting change available in real time.

**Four sources around an XY plane:**
```
        B (square)
         │
   A ────┼──── C
(sine)   │   (saw)
         │
        D (sample)
```
- The control position determines each source's contribution.
- Moving the position changes the mixture and therefore the timbre.
- Sources may be oscillators, samples, or a synthesis technique.
- The path may be controlled by a joystick, envelope, LFO, MIDI controller, or automation.

**Calculating Vector Weights — Bilinear Interpolation**
Converts an XY position into four source gains.

Source positions:
- A = (−1, 1)
- B = (1, 1)
- C = (−1, −1)
- D = (1, −1)

Source weights from XY position:
\[
w_A = \frac{1}{4}(1 - x)(1 + y)
\]
\[
w_B = \frac{1}{4}(1 + x)(1 + y)
\]
\[
w_C = \frac{1}{4}(1 - x)(1 - y)
\]
\[
w_D = \frac{1}{4}(1 + x)(1 - y)
\]

Constraints:
\[
0 \le w_A, w_B, w_C, w_D \le 1
\]
\[
w_A + w_B + w_C + w_D = 1
\]

Output (vector synthesis):
\[
y[n] = w_A \cdot s_A[n] + w_B \cdot s_B[n] + w_C \cdot s_C[n] + w_D \cdot s_D[n]
\]

**Static vs Dynamic Vector Mixing:**
| Static position | Dynamic trajectory |
|---|---|
| The four source weights remain constant | The source weights evolve continuously |
| The resulting timbre is a stable weighted mixture | The timbre moves through the source field |
| Useful as a starting point, but not the characteristic moving behaviour of vector synthesis | The path may be drawn, sequenced, or generated by envelopes, LFOs, or performance controls |

### Timbral Interpolation and Morphing
- Calculating intermediate states between two sound representations.
- Linear interpolation:
\[
y(t) = (1-\alpha)A(t) + \alpha B(t)
\]
\[
0 \le \alpha \le 1
\]
- \(\alpha = 0\) → A
- \(\alpha = 0.5\) → equal mixture (A + B)
- \(\alpha = 1\) → B

### Wave Sequencing
Scheduling different waves or samples over time.

Each step may specify:
- Source wave or sample
- Duration
- Pitch offset
- Amplitude
- Crossfade time
- Repeat or probability

**Example step list:**
| Step | Source | Time | Amplitude |
|---|---|---|---|
| Step 1 | Sine | 0 – 0.5 s | 0.80 |
| Step 2 | Square | 0.5 – 1.0 s | 0.65 |
| Step 3 | Saw | 1.0 – 1.5 s | 0.50 |
| Step 4 | Noise | 1.5 – 2.0 s | — |

**Result:** Sequential timbral evolution.

**Wave sequencing asks:** "Which source is active now, and what comes next?"

### Three Techniques at a Glance
| Technique | Main question | Control | Result |
|---|---|---|---|
| **Vector synthesis** | "What proportion of each source is heard now?" | XY position or source weights | A dynamic mixture |
| **Timbral interpolation** | "What lies between A and B?" | Interpolation factor | A continuous transition |
| **Wave sequencing** | "Which source is active now, and what comes next?" | Step list and timing | Sequential timbral evolution |

### Combined Architecture
A source can be simple, interpolated, sequenced, or an entire synthesis engine.

```
Wave sequence A ──┐
Wave sequence B ──┼──→ Vector Mixer ──→ Output
Wave sequence C ──┤
Wave sequence D ──┘
```

### Summary: Three Routes to Evolving Timbre
| Vector synthesis | Timbral interpolation | Wave sequencing |
|---|---|---|
| **SIMULTANEOUS** — several sources contribute at once | **CONTINUOUS** — intermediate states are calculated | **SEQUENTIAL** — sources are arranged as timed steps |
| Control: XY position or weights | Control: interpolation factor | Control: sequence data and timing |
| Programming idea: bilinear mixing | Programming idea: weighted interpolation | Programming idea: scheduling and crossfades |

**Shared goal:** Control how timbre changes over time.

## 3. Code

### 3.1 Load a Recorded Sample

```python
def load_sample(filename):
    sample_rate, audio = wavfile.read(filename)

    # Convert stereo to mono if needed
    if len(audio.shape) > 1:
        audio = np.mean(audio, axis=1)

    # Normalize
    audio = audio.astype(np.float32)
    audio = audio / np.max(np.abs(audio))

    return sample_rate, audio
```

### 3.2 Create a Note from a Sample (Pitch Shifting)

```python
def create_note_from_sample(sample, sample_frequency,
                            target_frequency,
                            duration_seconds):
    pitch_ratio = target_frequency / sample_frequency
    new_length = int(len(sample) / pitch_ratio)
    pitched_sample = resample(sample, new_length)
    target_length = int(duration_seconds * SAMPLE_RATE)

    # Trim or extend the sample
    if len(pitched_sample) >= target_length:
        pitched_sample = pitched_sample[:target_length]
    else:
        padding = target_length - len(pitched_sample)
        pitched_sample = np.pad(
            pitched_sample, (0, padding)
        )

    return pitched_sample
```

### 3.3 Synthesize an Event from a Sample

```python
def synthesize_event(event, sample, sample_frequency):
    target_frequency = pitch_to_frequency(event["pitch"])
    duration_seconds = beats_to_seconds(
        event["duration_beats"]
    )
    note_audio = create_note_from_sample(
        sample, sample_frequency,
        target_frequency, duration_seconds
    )
    return event["dynamic"] * note_audio
```

### 3.4 Build a Complete Melody

```python
def create_melody(events, sample, sample_frequency):
    total_beats = max(
        event["onset_beats"] + event["duration_beats"]
        for event in events
    )
    total_seconds = beats_to_seconds(total_beats)
    melody = np.zeros(int(total_seconds * SAMPLE_RATE))

    for event in events:
        note_audio = synthesize_event(
            event, sample, sample_frequency
        )
        start_sample = int(
            beats_to_seconds(event["onset_beats"])
            * SAMPLE_RATE
        )
        end_sample = start_sample + len(note_audio)
        melody[start_sample:end_sample] += note_audio

    melody = melody / np.max(np.abs(melody))

    return melody
```

### 3.5 Vector Mix (Bilinear Interpolation)

```python
def vector_mix(source_a, source_b, source_c, source_d,
               x, y):
    if not 0.0 <= x <= 1.0:
        raise ValueError("x must be between 0 and 1")
    if not 0.0 <= y <= 1.0:
        raise ValueError("y must be between 0 and 1")

    weight_a = (1.0 - x) * (1.0 - y)
    weight_b = x * (1.0 - y)
    weight_c = (1.0 - x) * y
    weight_d = x * y

    return (
        weight_a * source_a
        + weight_b * source_b
        + weight_c * source_c
        + weight_d * source_d
    )
```

### 3.6 Static Weighted Vector Synthesis

```python
def vector_synthesis(frequency, duration, amplitude):
    t = np.linspace(
        0, duration,
        int(SAMPLE_RATE * duration), False
    )

    # Four source waveforms
    sine_wave = np.sin(2 * np.pi * frequency * t)
    square_wave = square(2 * np.pi * frequency * t)
    saw_wave = sawtooth(2 * np.pi * frequency * t)
    triangle_wave = sawtooth(
        2 * np.pi * frequency * t, width=0.5
    )

    # Blend weights
    w1 = 0.4  # sine
    w2 = 0.2  # square
    w3 = 0.3  # sawtooth
    w4 = 0.1  # triangle

    signal = (
        w1 * sine_wave
        + w2 * square_wave
        + w3 * saw_wave
        + w4 * triangle_wave
    )

    # Normalize and apply loudness
    signal = signal / np.max(np.abs(signal))
    signal = amplitude * signal

    return signal
```

### 3.7 Render a Wave Sequence

```python
wave_sequence = [
    {"source": "wave_a", "duration": 0.20, "amplitude": 0.80},
    {"source": "wave_b", "duration": 0.30, "amplitude": 0.65},
    {"source": "wave_c", "duration": 0.10, "amplitude": 0.50},
]

def render_wave_sequence(steps, source_library,
                         sample_rate):
    rendered_steps = []
    for step in steps:
        source = source_library[step["source"]]
        required = int(step["duration"] * sample_rate)
        segment = source[:required].copy()
        segment *= step["amplitude"]
        rendered_steps.append(segment)
    return np.concatenate(rendered_steps)
```
